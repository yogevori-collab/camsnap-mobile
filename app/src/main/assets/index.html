1. Permissions (one time)

Snapshot service: …

Turn on CamSnap camera snapshots. It is what lets CamSnap open CAM2 and take snapshots on schedule.

Battery → Unrestricted, so Android never stops CamSnap.

Snapshots are taken from the screen, so use a dedicated phone: Screen lock = None, keep it on the charger, and turn on Stay awake in Developer options (tap Build number 7 times in About phone to show them).

2. CAM2 app

Pick Provision CAM2. CamSnap opens it before every snapshot.

3. Cameras

In CAM2, open the live view with the cameras you want (for example a 4-split) and leave it like that. Then press Mark cameras: CamSnap opens CAM2, takes a screenshot, and you draw a box over each camera picture.

5. Timing
